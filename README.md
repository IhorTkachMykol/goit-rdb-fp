# goit-rdb-fp — фінальний проєкт

Робота з датасетом `infectious_cases` (СУБД PostgreSQL, схема `pandemic`).
Весь SQL-код знаходиться у файлі [`final_project.sql`](final_project.sql).

## Виконання

1. **Завантаження даних.** Створено схему `pandemic`, встановлено `search_path`,
   створено таблицю `infectious_cases` та імпортовано `infectious_cases.csv`
   (Import Data у DBeaver / `\copy` у psql). Показники захворювань зберігаються як `TEXT`,
   оскільки в CSV є порожні значення.
2. **Нормалізація до 3НФ.** Створено дві таблиці:
   - `entities (id, entity, code)` — унікальні комбінації Entity + Code;
   - `infectious_cases_norm` — показники захворювань із зовнішнім ключем `entity_id`.
3. **Аналіз `Number_rabies`.** Для кожної країни/сутності пораховано AVG, MIN, MAX, SUM
   (тільки числові значення), результат відсортовано за середнім за спаданням, `LIMIT 10`.
   Датасет містить і агреговані записи (World, G20, регіони WHO/World Bank); їх не виключено,
   тому вони входять до топ-10 разом з Індією.
4. **Різниця в роках.** Через `MAKE_DATE`, `CURRENT_DATE` та `AGE` побудовано колонки:
   1 січня року, поточна дата, різниця в роках.
5. **Власні функції.**
   - `pandemic.year_diff(year)` — різниця в роках між поточною датою та 1 січня вказаного року;
   - `pandemic.avg_cases_per_period(cases, divisor)` — середня кількість захворювань за період;
     перевірено з дільниками 12 (місяць), 4 (квартал), 2 (півріччя).

## Скриншоти

- результати запитів із завдань 3, 4 та 5.
